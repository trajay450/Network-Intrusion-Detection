# Network Intrusion Detection — Synthetic Flow Benchmark

An independent machine-learning engineering demonstration using **synthetic** network-flow-like data. It compares a standardized logistic regression model with a random forest classifier.

## What is included
- Reproducible flow-like feature generation (duration, volume, packet count, failed logins, port entropy).
- Stratified train/test splitting; preprocessing fitted on training data only.
- Accuracy, precision, recall, F1 and ROC-AUC.
- JSON metrics export and automated tests.

## Run
```bash
python -m pip install -r requirements.txt
python -m pytest -q
python -m network_ids.benchmark
```
Results are printed and written to `outputs/metrics.json`.

## Critical limitation
Labels are generated by an explicit synthetic rule that also influences the input features. High scores therefore only show the pipeline can learn this simulated data; they **do not demonstrate real intrusion-detection capability, cybersecurity effectiveness, or robustness to domain shift**. No real network logs or restricted datasets are included. This is separate from unpublished TrustIDS research.

## Future extensions
Use approved public network datasets, patient-equivalent entity grouping where appropriate (e.g. capture-session splits), time-based evaluation, leakage audits, and actual cross-dataset tests.
